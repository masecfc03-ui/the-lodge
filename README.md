# The Lodge - Mason's Life OS

An interactive 2D virtual space built with Phaser.js, themed as a hunting lodge for business operations.

## ✨ Features

- **9-Room Interactive Lodge**: Navigate through themed rooms with WASD/arrow keys
- **Business Dashboard**: Each room contains relevant business data and controls
- **Mobile Support**: Touch controls with virtual joystick (nipplejs)
- **Responsive Design**: Adapts to desktop and mobile screens
- **Real-time Data**: Live clock, statistics, and activity feeds

## 🏠 Room Overview

1. **Base Camp (Fireplace)**: Welcome dashboard with weather, stats, and inbox
2. **Projects (Desk)**: Active projects with Wholesaling pipeline and Kalshi trading
3. **The Team (Bunks)**: Team member status and activity tracking
4. **Treasury (Safe)**: Financial overview and expense breakdown
5. **Command Center (Radio)**: Campaign controls and system health
6. **Jukebox**: Music controls and playlist selection
7. **Field Journal (Bookshelf)**: Searchable leads database (16,663+ leads)
8. **Trail Cams (Monitors)**: Live notification feed with filtering

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🎮 Controls

- **Movement**: WASD or Arrow Keys
- **Interact**: E key (or touch button on mobile)
- **Close Panel**: ESC key or X button
- **Mobile**: Virtual joystick + interact button

## 🛠 Built With

- **Phaser.js**: 2D game engine
- **Vite**: Build tool and dev server
- **nipplejs**: Virtual joystick for mobile
- **Vanilla JS**: No framework dependencies
